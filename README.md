# Parse FunTime

Парсер чата для серверов FunTime. Генерирует события `chat:message` для обработки командами.

## Как работает

Плагин слушает сырые сообщения и парсит 4 типа чатов:

| Тип | Формат | Пример |
|-----|--------|--------|
| `chat` (локал) | `Ⓛ [Донат] ник ⇨ сообщение` | `Ⓛ [Игрок] bananagnimus ⇨ привет` |
| `global` | `Ⓖ [Донат] ник ⇨ сообщение` | `Ⓖ [Элита] yan_trays1 ⇨ привет всем` |
| `private` | `[[Донат] ник > Я] сообщение` | `[[Игрок] akrem > Я] привет` |
| `clan` | `[Клан] ник » сообщение` | `[Клан] akrem » привет клан` |

## События

Плагин эмитит событие `chat:message` с данными:

```javascript
{
  type: 'chat' | 'global' | 'private' | 'clan',
  username: 'PlayerName',
  message: 'текст сообщения',
  jsonMsg: { /* оригинальный JSON сообщения */ }
}
```

## Регистрируемые типы чатов

- `chat` — локальный чат (без префикса)
- `global` — глобальный чат (префикс `!`)
- `clan` — клановый чат (префикс `/cc `)
- `private` — приватные сообщения (префикс `/msg `)

## Настройки

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| Задержка локального чата | number | 3000 | Задержка в мс |
| Задержка глобального чата | number | 3000 | Задержка в мс |
| Задержка кланового чата | number | 500 | Задержка в мс |
| Задержка приватного чата | number | 3000 | Задержка в мс |
